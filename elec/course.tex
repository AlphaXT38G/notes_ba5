\chapter*{Comment lire ces notes}
\addcontentsline{toc}{chapter}{Comment lire ces notes}

Ces notes reprennent le cours \emph{Électronique I} (E.~Zysman et J.-M.~Sallese, EPFL,
automne 2026), chapitre par chapitre, à partir des diapositives \textbf{et de leurs
commentaires}. Rien n'est inventé : chaque formule et chaque exemple vient du cours. Quand
une phrase explique avec d'autres mots ce que dit le cours, elle reste fidèle à son contenu.

Chaque chapitre contient :
\begin{itemize}
  \item les définitions, lois et formules du cours, dans des boîtes de couleur
        (vert : définition, rouge : théorème/loi, bleu : propriété, orange : attention,
        gris : remarque, exemples en encadré) ;
  \item \textbf{les captures des diapositives} pour chaque schéma, graphe et exemple, avec
        l'explication de ce qu'il faut y voir ;
  \item \textbf{des boîtes brunes, \og Expliqué à une chèvre\fg{}} : l'idée de la section
        avec les mots les plus simples possibles, à lire d'abord quand une définition ne
        passe pas ;
  \item \textbf{une grande boîte violette à la fin, le \og Récap pour l'examen\fg{}} : tout ce
        qu'il faut savoir, assez court pour être relu la veille, assez complet pour être
        compris seul. Chaque récap dit aussi \textbf{comment le chapitre s'appuie sur les
        précédents}.
\end{itemize}
Le dernier chapitre est un \textbf{récapitulatif général pour l'examen} : toutes les
formules, les méthodes pas à pas et les pièges classiques.
